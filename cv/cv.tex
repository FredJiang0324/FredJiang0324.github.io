\section*{Research Experience}
\role{Graduate Research Assistant, The University of Texas at Dallas}{Department of Computer Science}{Aug 2024 -- Present}
\begin{itemize}
  \item \textbf{Agentic memory architectures:} Designed MAGMA, a multi-graph agentic memory system for LLM agents (ACL 2026, first author), and HAGE, an RL-driven weighted graph-evolution memory module (under review, first author).
  \item \textbf{Empirical analysis \& benchmarking:} Built a taxonomy and empirical study of agentic-memory systems, designing evaluation benchmarks with adversarial question categories to expose system limitations (under review, first author).
  \item \textbf{Retrieval systems:} Contributed to a scalable disk-based approximate nearest neighbor search system with a page-aligned graph index (under review).
  \item \textbf{Foundation models for scientific computing:} Contributed to PDE foundation models for 3D-IC thermal simulation (DAC 2026) and PDEAgent-Bench, a benchmark for PDE solver generation.
  \item Research supported by multiple U.S. National Science Foundation (NSF) awards.
\end{itemize}
